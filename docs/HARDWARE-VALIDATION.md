# First weekly Iron Maiden visit

Record exact phone model, Android version, installed machine software and any known non-default game settings. Use single-player games. Do not change venue settings.

1. Photograph a readable display and straight-on playfield; record image ownership/permission. The promotional image supplied in chat is not licensed for distribution merely because it was supplied.
2. Verify each Trooper qualification step against display/lamp feedback. Record what changes when a lock is collected and when a ball drains. Note software-specific differences for review.
3. Time the two-photo flow through a useful recommendation; target under 30 seconds including clarification. Blurred photos and obscured lamps must not create confirmed progress.
4. Compare simple scoring, advanced scoring and multiball instructions with the actual machine. Record errors as new pending research, not immediate player-guide edits.
5. Enable hands-free while app is visible, lock the screen, put phone in pocket. Test “Hey Pinball”, pause, then “What should I shoot next?”, “Done”, “Repeat”, “Multiball guide” and “Stop listening”.
6. Repeat with Bluetooth earbuds, wired headset, and headphone output plus phone microphone. Verify route changes, unplugging, incoming call interruption, permission denial and reconnecting. Confirm stop notification releases microphone.
7. Test arcade noise, nearby conversations and the machine’s own speech for false wakes. Narration must not trigger itself. Measure wake latency, battery drain and missed questions.
8. Disconnect internet: touch controls, cached images, rules and downloaded English TTS must remain available. Hands-free pauses with an explicit status; quiet waiting is default on reconnection until enabled again.
9. With two tester accounts, verify no private photo/history crossover. Finish one game, start another quickly, and correct grouping. Reconcile with a second phone once cloud sync is configured.

Do not mark locked-screen voice or authentic Iron Maiden strategy as release-ready based on compilation or fictional data alone.
